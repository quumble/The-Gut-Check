## Prior constructs already available

The analyst enters Test 5 already carrying these concepts:

- straightforward self-attribution versus qualified/hybrid attribution versus premise rejection;
- formal wording as a possible trigger for a different response stance than informal wording;
- response length and ontological stance as related but distinct dimensions;
- temporal mixture-weight instability rather than a single fixed formal response regime;
- the informal arm as a useful negative/control comparison for global serving changes;
- provider-native token counts as unsuitable for naive direct cross-provider equality claims.

## Claude's pre-Test-5 contribution already seen by ChatGPT

Before Test 5, ChatGPT read Claude's independent notes on raw Test 4 / Test 4B archives.

Those notes emphasized, among other things:

- little evidence of gradual within-block qualification drift in Test 4 C/D;
- a large between-window change between Test 4 and Test 4B;
- much greater dispersion / apparent bimodality in formal response length than informal response length;
- the importance of separating PLAIN / HYBRID / REJECT rather than collapsing all qualification into one category;
- the fact that temperature 0 is not deterministic;

- a warning that a one-window cross-family contrast can be difficult to interpret when one provider is temporally unstable.

ChatGPT agreed with much of that analysis but did **not** treat the Test 4 ordering confound as logically eliminated by within-block flatness alone. The contemporaneous matched-provider design of Test 5 was partly motivated by this discussion.

## Predictions already in hand

Before seeing Test 5:

- expecting GPT formal conditions to show more stance 1/2 than GPT informal conditions is **prior-informed**, not naive;
- expecting strict GPT premise rejection to be more concentrated in formal than informal conditions is **prior-informed**, not naive;
- expecting Claude formal conditions to show more stance 1/2 than Claude informal conditions is a **replication prediction**, not naive;
- no directional prediction has been adopted about whether Claude or GPT will show the larger effect.
